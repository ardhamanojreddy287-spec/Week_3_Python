# Week 3 - Python OOP Projects

## Overview

This repository contains my Week 3 Python programming tasks based on Object-Oriented Programming (OOP), classes, objects, methods, and exception handling.

## Tasks Completed

### 1. Bank Account

**File:** `bank_account.py`

A simple bank account program demonstrating:

- Classes and objects
- Account balance
- Deposit operation
- Withdrawal operation
- Balance display
- Basic validation

### 2. Library Management System

**File:** `library_management.py`

A library management program that demonstrates:

- Classes and objects
- Adding books
- Removing books
- Issuing books
- Returning books
- Displaying book availability

### 3. Calculator with Exception Handling

**File:** `calculator.py`

A calculator program demonstrating:

- Object-Oriented Programming
- Addition
- Subtraction
- Multiplication
- Division
- Exception handling
- Handling division by zero
- Handling invalid input

### 4. Billing System Mini Project

**File:** `billing_system.py`

An OOP-based billing system demonstrating:

- Product class
- Bill class
- Product price and quantity
- Subtotal calculation
- GST calculation
- Grand total calculation
- Tabular bill display

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Exception Handling

## How to Run

Open the project folder in VS Code and run the following commands in the terminal:

```bash
python bank_account.py
```

```bash
python library_management.py
```

```bash
python calculator.py
```

```bash
python billing_system.py
```
